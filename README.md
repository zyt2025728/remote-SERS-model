# 2D SERS nanoparticle network

This repository contains a reproducible coupled-dipole approximation (CDA)
simulation of a weakly disordered two-dimensional silver nanoparticle network.
The particles are driven by a localized, z-polarized 633 nm field. Retarded
dipole interactions and radiation correction of the quasistatic silver-sphere
polarizability are included.

Run the complete model with:

```bash
python run_2d_sers_model.py
```

Particle-level complex dipoles and local fields, distance-binned propagation
data, a numerical summary, and four figures are written below `results/`.
