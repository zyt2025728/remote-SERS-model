# Level 3A.5 — hotspot-propagation validation

This analysis exactly regenerates the Level 3A seed, geometry, excitation, PDA
solution, and hotspot network. The strongest source hotspot is the sole launch
reference; source classification does not set distance to zero.

Global attenuation describes an overall distance trend. Local downstream
enhancement is only a neighboring, farther hotspot having larger uncalibrated
`M4`; it is not energy amplification or an energy-flow pathway. Threshold maps
separate any, 2x, 10x, and 100x relations.

No Poynting map is produced because the current solver has no consistent
magnetic-field reconstruction. Graph directions were not substituted for power
flow. This remains uncalibrated PDA analysis: no calibrated SERS, ensemble,
attenuation fit, Level 3B, or macroscopic extrapolation is included.
