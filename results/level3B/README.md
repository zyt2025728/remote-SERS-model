# Level 3B outputs

This directory contains the final matched-PDA versus frozen 32-case MiePy GMMT
dimer calibration and its application to the immutable Level-3A.5 network.
`data/gap_calibration_table.csv` contains complex parallel and perpendicular
corrections; `data/component_correction_validation.csv` contains the independent
30/60 degree validation; and `data/network_hotspots_fullwave_corrected.csv`
contains the complex corrected network field and electromagnetic M2/M4 proxies.

The production full-wave backend is `miepy_GMMT`. COMSOL numerical status is
**NOT EXECUTED**. See `LEVEL3B_STATUS.md` for provenance, the validation gate,
rank statistics, downstream statistics, and scientific interpretation.
